                                                                                                                                                                                                          • 必殺技、超必殺技與CLIMAX超必殺技： 各自的性能、傷害、氣槽消耗，以及在連段和壓制中的應用。

                                                                                                                                                                                                          4. 對戰相性與陣容搭配建議

                                                                                                                                                                                                          • 團隊協同： 在3v3模式下，該角色與哪些隊友能產生良好化學反應，形成互補或強化戰術。
                                                                                                                                                                                                          • 先鋒/中堅/大將定位： 根據角色特性，建議其在隊伍中的出場順序與戰術考量。
