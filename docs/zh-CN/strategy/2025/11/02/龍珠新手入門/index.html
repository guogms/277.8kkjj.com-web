                                                                                                                                                                                                          • 气（Ki）： 这是您施放气功波、超级攻击和究极攻击的能量来源。学会如何有效积蓄气（通常是按住特定按钮）和合理消耗，是战斗的重中之重。在战斗中，保持足够的气量，才能随时应对突发状况。
                                                                                                                                                                                                          • 体力（Stamina）： 体力用于回避、瞬移（Z-Vanish）和防御。体力耗尽会让您进入短暂的虚弱状态，容易被敌人连击。因此，合理使用回避和防御，避免体力归零，是保护自己的重要手段。

                                                                                                                                                                                                          2. 近战（Strike）与气弹（Ki Blast）攻击

                                                                                                                                                                                                          • 近战攻击： 大多数角色都拥有强力的拳脚连击。学会基础连段，并在连段结束时接续超级攻击，能打出可观的伤害。
                                                                                                                                                                                                          • 气弹攻击： 远距离消耗战的利器。有些角色的气弹攻击速度快、追踪性强，适合牵制敌人或打断其行动。根据敌人的距离和攻击模式，灵活切换近战与气弹，是资深玩家的常用策略。

                                                                                                                                                                                                          3. 超级攻击（Super Attack）与究极攻击（Ultimate Attack）

                                                                                                                                                                                                          • 超级攻击： 消耗少量气，威力适中，是您战斗中的主要输出手段。例如龟派气功、魔闪光等。根据战况选择合适的超级攻击，例如击飞、追踪或范围攻击。
                                                                                                                                                                                                          • 究极攻击： 消耗大量气，但威力惊人，是逆转战局或终结敌人的大招。例如元气弹、超龟派气功等。由于消耗大，应在确保命中的情况下使用，或作为连段的终结技。

                                                                                                                                                                                                          4. 防御与回避

                                                                                                                                                                                                          • 格挡（Guard）： 按住防御键可以减少受到的伤害。但请注意，防御无法抵挡所有攻击，且持续防御会消耗体力。
                                                                                                                                                                                                          • 回避（Evasion）： 消耗体力进行瞬移或快速闪避，是躲避敌人攻击的关键。学会读取敌人动作，在攻击来临前精准回避，能让您在战斗中游刃有余。

                                                                                                                                                                                                          • 重要性： 等级提升会增加角色的基础属性（生命值、攻击力等），并解锁新的技能或装备栏位。初期建议优先完成主线任务，快速提升等级。

                                                                                                                                                                                                          2. 属性点分配（仅适用于部分RPG游戏，如《异战2》）

                                                                                                                                                                                                          • 在《异战2》这类RPG游戏中，每次升级都会获得属性点，您可以自由分配到生命力、气、体力、基本攻击、气弹攻击或超级攻击等属性上。

                                                                                                                                                                                                          3. 技能（Skills）与究极技（Ultimate Skills）

                                                                                                                                                                                                          4. 装备与灵魂（Souls/Z-Souls）

                                                                                                                                                                                                          • 装备： 提供额外的属性加成，有些甚至能改变角色的外观。
                                                                                                                                                                                                          • 灵魂（Z-Souls）： 在《异战2》中，Z-Souls（或称超魂）能提供各种特殊效果，例如战斗开始时自动回复气、提升特定攻击的威力，或在体力耗尽时触发特殊效果。选择合适的Z-Soul，能极大提升您的战斗力。
