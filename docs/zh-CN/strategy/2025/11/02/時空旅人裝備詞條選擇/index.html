                                                                                                                                                                                                          1. 什么是装备词条？

                                                                                                                                                                                                          裝備詞條（或稱詞綴、屬性）是賦予裝備額外能力的屬性，例如「+10% 暴擊率」、「+500 生命值」、「技能冷卻時間縮短 5%」等。它們是構成你角色 Build 的基石。

                                                                                                                                                                                                          2. 主要词条 vs. 次要词条

                                                                                                                                                                                                          • 主要词条 (Primary Stats)：通常是装备上数值最高、影响最大的词条，例如武器上的「攻击力」、防具上的「护甲值」或「主要属性」（力量、敏捷、智力等）。这些词条的数值高低直接影响装备品级。
                                                                                                                                                                                                          • 次要词条 (Secondary Stats)：除了主要词条之外的额外属性，如暴击率、暴击伤害、冷却缩减、资源回复等。这些词条的搭配与优化是打造高效 Build 的核心。

                                                                                                                                                                                                          3. 词条的「品质」与「潜力」

                                                                                                                                                                                                          每个词条都有其数值范围，高「品质」的词条意味着其数值接近上限。而「潜力」则是指该词条在当前 Build 中的重要性。一个看似数值不高的词条，若能完美契合你的流派，其潜力可能远超一个高数值但不搭嘎的词条。
